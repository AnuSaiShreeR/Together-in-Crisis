TogetherInCrisis

TogetherInCrisis is a full-stack web application designed to connect volunteers, individuals, NGOs, and disaster-relief organizations. The platform aims to improve coordination, resource allocation, and community participation during emergencies and social initiatives.

Overview

The platform supports both crisis volunteering and casual volunteering, helping users discover opportunities and participate in meaningful community activities.

Features

User Authentication: Sign-up, sign-in, and password recovery.

Volunteer Profiles: Manage user details and track volunteering activities.

Volunteer Type Selection: Choose between crisis volunteering and casual volunteering.

Events Management: Browse volunteering opportunities and crisis-related events.

Event Registration: View event details and register for volunteering activities.

Professional Profiles: Track volunteer participation and attendance.

Testimonials: Share volunteer experiences and inspire community participation.
